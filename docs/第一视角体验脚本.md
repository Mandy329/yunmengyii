# 《一直都这样》第一视角体验脚本

> 用法：这份文档是**给队友看的剧本**，不是设计说明。
> 每一屏都写到「能看到什么、能做什么、屏幕上写什么字」，照着做即可，不需要再开会讨论。
>
> 全片尺寸：**约 4 分 30 秒 ｜ 4 屏 ｜ 一局通关 ｜ 零菜单 ｜ 零教程**

---

## 全片四屏

| 屏 | 名字 | 时长 | 玩家身份 | 交还给他 | 情绪目标 | 出口条件 |
|---|---|---|---|---|---|---|
| **S0** | 门面（平面） | 20–45s | 路人 | — | 好奇、被挑衅 | 点下「推门进去」 |
| **S1** | 认命 | 60–90s | 办事的人 | — | 烦躁 → 麻 | 被退回第三次 |
| **S2** | 觉醒 | 25–40s | 有权修改的人 | 身体 / 意识 / 时间 | 起鸡皮疙瘩 | 改动一次并见效 |
| **S3** | 剥离 | 40–60s | 带着方法离开的人 | 一副眼睛 | 安静、想截图 | 写下自己的那条 |

**铁律：顺序不可颠倒。** 没有 S1 的憋屈，S2 的爽就是廉价的；没有 S2 的夺回，S3 的说教就是空的。

# S0｜门面：一张盖着旧章的纸

> 你负责的这一屏。它不是加载页，**它就是第一个画面**。

## 你看到什么（第一人称）

我打开的瞬间不是游戏，是一张纸。

左上角盖着一个歪掉的红色日期章：**1998.11.03**。
纸的中央画着一条流程线，六个方块串起来：取号 → 核验 → 复印 → 盖章 → 取件 → 出门。
第三格「复印」那里，红线正在慢慢地自己打一个结，又松开，又打上。

正中央最大的一行字是灰色的，像被人反复擦过的铅笔字：

> **有一条 1998 年的规定，今天还在这里生效。**

右下角一行小字在跳：**本站已连续 9,855 天执行同一条临时规定。**

再仔细看，纸是有厚度的——磨砂玻璃后面，那座大厅已经在运转了：人影来回穿，纸在飞，只是隔着一层雾。我隐约听见打印机在响。

我意识到的第一件事不是"这是个什么游戏"，而是：**这地方真的有人在排队。**

## 你能做什么（只有三样）

| 元素 | 行为 |
|---|---|
| 主按钮 **「推门进去 →」** | 唯一的大按钮，唯一的下一条路 |
| 次按钮 **「先看 20 秒演示」** | 不点它也没关系——它自己会演 |
| 角落 | 静音开关 |

**永远不超过三个可点元素。** 这一屏的任务只有一个：让他伸手推门。

## 屏幕上写什么字（可直接复制）

```
眉标      CHAPTER 01 · 惯例街道 包裹领取站
主标题    一直都这样
英文副标  THE WAY IT'S ALWAYS BEEN
挑衅句    有一条 1998 年的规定，今天还在这里生效。
数据贴纸  今日第 128 位 ｜ 平均等待 04:30 ｜ 全流程 6 步
主按钮    推门进去 →
次按钮    先看 20 秒演示
跑马灯    本站已连续 9,855 天执行同一条临时规定
          · 全城共 1,204 条「临时」规定等待复核
          · 你有权修改它
流程线    取号 → 核验 → 复印 → 盖章 → 取件 → 出门
```

> **文案纪律**：主标题用黑体，数字用 Georgia（衬线数字的"档案感"），其余全部 ≤ 12px。
> 英文副标出现但不翻译——它让画面像一份文件，而不是一张游戏封面。

## 构图五层（从底到顶，照着码）

```
1  纸底        #f5f3e9 + 极淡网格点（13px），沿用现有 CSS 变量 --paper
2  背景层      已有的 canvas 场景，filter: blur(6px) brightness(1.06)
               ← 这层是绝招，见下方"为什么要点进去"
3  流程线      六个方块 + 一条描边 2px 的红线（--coral #ce765d）
4  文字层      左上日期章 rotate(-5deg) ／ 中央挑衅句 ／ 底部跑马灯
5  按钮层      右下，实心 --green #34594a 底 + 米白字，唯一高对比元素
```

**配色一个都不用新想，全部取自现有 demo 的 CSS 变量**：
`--paper #f5f3e9` `--ink #293e37` `--green #34594a` `--mint #cbdcc6` `--coral #ce765d` `--yellow #edcc84` `--blue #a0b7be`

## 演出指令（成本极低，但决定"贵不贵"）

| # | 东西 | 时长 |
|---|---|---|
| 1 | 红线在第三格缓慢打结／松开 | 3s 循环 |
| 2 | 「今日第 128 位」每 5 秒 +1 | 全程 |
| 3 | 跑马灯匀速横移 | 全程 |
| 4 | 背景大厅模糊层持续运转（已有 3D 直接用） | 全程 |
| 5 | **点击推门**：浮层 `opacity→0`、`scale 1→1.02`、`blur 12px→0`，场景 `scale 0.96→1` | 0.6s |
| 6 | 音效：翻纸一声「哗」＋远处一记打印机吐纸 | 0.8s |

## 为什么这屏能让评委在点进去之前就买账

1. **它不是暂停画面，是磨砂玻璃。** 3D 场景在浮层后面已经跑起来了，点「推门」只是去掉滤镜——**从点击到看见人，零等待**。这一条同时消灭了加载页和第一帧冷启动。
2. **它给的是挑衅，不是说明。** 不解释玩法，只丢一句无法忍住的问题：为什么还在？
3. **它自带截图属性。** 日期章 + 衬线数字 + 一句狠话，配上 12 个字就能发。

## 验收标准（你自己对着打勾，不用问任何人）

- [ ] 5 秒内看懂「这是个关于规定的游戏」
- [ ] 不看任何提示，能找到唯一那个按钮
- [ ] 从点击到看见人 ≤ 0.8 秒
- [ ] 静音状态下，这一屏依然成立
- [ ] 缩放到 1280 宽和 375 宽都不塌（对照现有 media query）
- [ ] 截图发朋友圈，配文不用改第二遍

# S1｜认命：请先证明你排过队

> 60–90 秒。这一幕的目标只有一个：**让玩家的身体先记住顺从。**

## 你看到什么（第一人称）

推门的一瞬间，噪声扑过来。一百多号人。六个窗口全开着，但所有人都在往左边角落挤——那儿只有一台复印机。队伍绕了三圈，地上全是白花花的纸。

广播在念，语速永远不变：

> 「A037 号，请到 3 号窗口。」
> 「办理前请先出示**纸质凭证副本**。」

我低头看看自己手上：一张单子，空的。行吧，照大家说的做。

于是我开始跑。**取号 → 核验 → 复印 → 盖章 → 取件 → 出门**，一步都不能跳。
取好的号被要求重新排；核验完发现顺序不对，再排；复印机前永远有七个人；盖完章被说"顺序不对"，退回去重来。

我走得很慢。**不是我不肯跑，是这个身体在这套规则里跑不起来。**

中途我看到右边那个面板：修改规定。我点了一下。

> **「你还没有资格修改规定。」**

好。那就继续排。

## 你能做什么／不能做什么

| 能 | 不能 |
|---|---|
| 一步一步走完六步 | 跳过任何一步 |
| 用「搭把手」帮一个顾客 | 让队伍真的变短 |
| 看着它越来越堵 | 打开修订台（灰） |
| 提出「再买一台复印机」 | 让广播停下来 |

**「再买一台复印机」必须可用，而且必须失败。**
第二台机器砸下来，队伍短了两秒，然后又堵死——因为每个人**还是**要先复印再回窗口。

## 这一幕必须出现的字

```
广播        A037 号，请到 3 号窗口。办理前请先出示纸质凭证副本。
广播        A037 号，您的章不符合规定。
广播        请重新排队。
修订台      你还没有资格修改规定。
站长老周    你先按现在的流程跑一遍吧。我们一直都是这么办的。
 ending     （第三次被退回时）……这也太离谱了吧。
```

## 演出指令

- 镜头（第一人称视角）**每次到下一站时自动转过去**——"看什么"不由你
- 移速压到正常值的 60%，且会被队伍挤住
- 纸屑粒子越积越多；随时间全场色温由 `#f5f3e9` 缓慢偏黄变灰
- 广播每 6–8 秒一次，语速、音量**恒定不变**（这才有被规训感）
- 全程无音乐，只有环境噪声

## 出口条件

**被盖章台退回第三次。** 只有这一条，不看倒计时。
这是为了防止"看完动画就觉醒"——必须让他真的被退回来过三次。

## 情绪验收

- [ ] 玩家会说出「这也太离谱了吧」
- [ ] 玩家**尝试过**点修订台（说明他在找权力）
- [ ] 玩家**用过**「买第二台复印机」（说明他相信了站长的方案）

# S2｜觉醒：这一段告訴你，它不是天生如此

> 25–40 秒。全片最重要的一段。12 秒倒带 + 三件工具。

## 你看到什么（第一人称）

第三次被退回来的时候，我发现：**我终于可以自己转头了。**

之前都是别人替我转的。这一刻，视线回到了我自己手上。

我开始敢看别的东西。转身，走到那面贴满通知的墙前。一张发黄的纸，卷了边：

> **「扫描设备维修期间，请暂时留存纸质复印件。1998.11.03」**

我顺着纸上那个褪色的箭头看过去——

角落里，**一台扫描仪正在垫花盆**。盆里的绿萝长得挺好。

我伸手把它点开。

然后世界倒着走了。

地上的纸飞回复印机，顾客倒着退回门口，印章从纸上抬起来。颜色由灰黄慢慢暖回来。画面停在 1998 年的那一天——打印机刚刚坏掉的那天。真安静。

屏幕上浮出两个选项，像有人在问我：

> A. 修好它（要打报告，很贵）
> B. 让顾客自带复印件（今天就能解决）
>
> **「他选了 B。这在当时，是合理的。」**

然后快进：规定长出了第二个章、第三个窗口、第二台复印机。噪声一层一层叠上来，越来越吵。回到现在这个堵死的大厅。定帧。

> **「当时那个选择是合理的。
> 但现在，你可以替他重做一次。」**

手边那支笔，亮了。

## 停顿。这句话必须在屏幕上停留够久。

## 三件工具（逐个给，顺序不可换）

每一件都对应一种被夺回的权力，这是可以直接讲给评委听的设计。

| 顺序 | 工具 | 夺回什么 | 提示语变化 |
|---|---|---|---|
| 1 | **搬运手套** | 身体／空间 | 「从来没有摆错的东西，只有懒得搬的人。」 |
| 2 | **修订笔** | 意识／规定 | 「你还没有资格修改规定。」→「**你有权修改它。**」 |
| 3 | **退还计时器** | 时间 | 不是工具，是账本。你改完它才开始跳 |

## 演出指令（12 秒倒带，不要做真物理倒放）

按 `三幕结构.md · 附录 C` 的分镜执行，实现方式记死：
**录制一遍正常流程里关键物体的位置序列，反向插值播放**（预置关键帧）。比实时倒放便宜十倍，且完全可控。

| 秒 | 画面 | 声音 |
|---|---|---|
| 0–1 | 全场去色，只留「复印」一步亮红。字幕：「有 128 人，正在为这张纸打工。」 | 环境音抽空，只剩心跳 |
| 1–5 | 倒带：纸飞回机器、人倒着走、章从纸上抬起 | 倒放音 + 磁带咔哒 |
| 5–6 | 停在 1998 年那天的安静 | 静音 |
| 6–9 | 弹出当年的 A／B 两个选项 | **音乐第一次出现** |
| 9–12 | 快进：规定一层层长出。回到堵死的大厅 | 噪声层层叠加 |
| 12 | 定帧，字幕，笔亮起 | — |

## 这一幕必须出现的字

```
墙上通知    扫描设备维修期间，请暂时留存纸质复印件。 1998.11.03
倒带字幕    有 128 人，正在为这张纸打工。
历史字幕    他选了 B。这在当时，是合理的。
定帧字幕    当时那个选择是合理的。但现在，你可以替他重做一次。
笔的提示    你有权修改它。
```

## 出口条件

**完成一次有效改动**（例如：把扫描仪从花盆底下拖出来 → 规定改为「任一种有效凭证」→ 核验与取件并成一条线）。

改动生效的那一秒，必须出现全片最重要的一行字：

> **你为每位市民退还了 4 分 30 秒。**

# S3｜剥离：删掉之后，人去哪了

> 40–60 秒。注意：这一幕有一半是"代价"，砍掉它，整个作品就降级成爽文。

## 你看到什么（第一人称）

我改完了。复印机"咔"地塌下去，变成一张长椅。大厅背景由灰黄渐变成暖白，噪声条掉下来，三个员工坐下了，其中一个在喝水。

新一批顾客进来。骑手扫码就走，11 秒搞定。太爽了。

然后我看见一个老人站在自助机前，不动。他不会用。
还有一个手机没电的人，举着黑屏的手机到处找人。

我愣了一下：**我把大厅里的排队，搬到了他们身上。**

我拖了一个员工过去，改成「自助 + 人工协助位」。他们办成了。效率低了十几个百分点，但没有人是白跑一趟。

## 结算（四维，一个都不能少）

```
办理时长     04:30 → 01:10        ↓ 74%
运营成本     ¥  — → ¥  —          ↓   %
差错件数      12  →   2           ↓ 83%
员工疲劳      高  →   中          ↓   （这一项专门用来抓"甩锅"）

本次共退还 137 小时
```

**员工疲劳这一项存在的唯一目的**：阻止玩家把大厅的等待转嫁成员工后台加班。
> **负担不能转移，只能消失。**
> 这一句讲出来，评委就知道我们是真想过的。

| 整改前 | 整改后 |
|---|---|
| 百人排队 · 灰黄 · 满地纸屑 | 空荡大厅 · 暖白 · 有人坐着喝水 |

## 最后一屏：剥离单

结算不是终点。**结算的最后一屏是一个输入框。**

```
┌──────────────────────────────┐
│  你已经在这座城市删掉了一条。  │
│                              │
│  「请写出一条你身边·          │
│    一直都这样的规定。」        │
│                              │
│  [ ______________________ ]  │
│                              │
│        [ 剥离它 ]            │
└──────────────────────────────┘
```

输入后生成一张卡（五段结构，固定）：
**规定 → 每年消耗 → 当年为什么设它 → 现在为什么不必了 → 重做建议**
收尾签名句永远不变：**「你有权修改它。」**

可保存、可分享、可扫码带走。

> 3D 这一局只是训练场，**输入框才是本体**。

## 最后一句字幕

> **世界不会自己变好，
> 是有人把多余的那一层撕掉了。**

画面：曾经摆满复印机的地方，现在放着一张长椅。有人坐在那里喝水。

## 情绪验收

- [ ] 玩家在结算页停留 ≥ 8 秒（看对比图）
- [ ] 玩家真的输入了自己的那条
- [ ] 玩家点了「保存图片」

> 我们做了一座所有人都觉得不对、但所有人都习惯了的城市。
