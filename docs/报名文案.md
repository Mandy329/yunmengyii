# 给「报名填写 Agent」的完整提示词

> **用法**：把下面「复制区」里的整段内容，原样粘给一个新对话的 AI，然后告诉它你要填哪张表、每栏多少字。
> 它不需要看代码，下面这些事实足够它写出全部报名文案。

---

## 复制区（从这里开始复制）

```
你是一位黑客松报名文案专家。请帮我填写比赛报名信息。

【作品名称】
一直都这样

【Slogan / 副标题】
一直都这样——但一直都这样，不代表就该这样。

【一句话介绍（30 字）】
一款第一人称 3D 游戏：你删掉过期规定，把被征收的等待时间还给人。

【一句话介绍（50 字）】
你接手快倒闭的「流程维修事务所」，走进一座所有人都习惯了的城市，
找出那条早就该失效的规定，亲手删掉它，把时间还给被它拦住的人。

【一句话介绍（100 字）】
《一直都这样》是一款第一人称 3D 网页游戏。玩家是「城市流程维修事务所」的善后员，
走进一座所有人都觉得不对、但所有人都习惯了的城市。这里所有临时规定都永久有效：
一张 1998 年的通知让十二个人反复排队、复印、盖章。玩家先被这套流程折腾，
再发现病根，最后亲手删掉多余的一步——每删一层，就把一笔被征收的等待时间还给人。

【我们解决的问题】
历史遗留规定从不失效。二十年前设备坏了，于是要求留存纸质复印件；
设备修好后，规定留下了。
问题不是没人发现，是**发现的人没有改动权**。本作品把改动权交给玩家。

【核心理念（最重要，必须体现）】
1. 等待不是天经地义的，等待是被设计出来的——所以它可以被重新设计。
2. 可以检验的减法，才是 Redesign。结算里的「员工疲劳」专门用来阻止玩家
   把一个地方的负担转移到另一个地方。**负担不能转移，只能消失。**
3. 重做的不是某个物件，是「一个人面对规则时的位置」：从服从者，变成有权修改者。
4. 退还时间的终点不是效率，是一个人本来该有的一天。

【三幕结构】
第一幕 认命：十二个人把大厅塞满，广播每 5 秒催一次，移速被压到 60%，
          点「修改规定」只会得到「你还没有资格修改规定。」
第二幕 觉醒：发现 1998 年的旧通知，倒带回那天——当年打印机坏了，
          负责人选了「让顾客自带复印件」，「这在当时，是合理的」。
          此后规定长出第二个章、第三个窗口、第二台复印机。
第三幕 剥离：删掉那一步，复印机塌成长椅，员工坐下喝水。
          结算出现四个数字（时长/成本/差错/员工疲劳），
          以及「你为每位市民退还了 X 秒」。
          最后一屏是输入框：请玩家写下自己身边那条「一直都这样」的规定，
          生成可保存、可分享的「剥离单」。

【玩法机制】
- 第一人称 3D 探索：WASD 走，鼠标转头，E 与人和设备交互
- 三件工具＝三种被夺回的权力：搬运手套（空间）、修订笔（规则）、退还计时器（时间）
- 三条可改的规定 + 六张改造券（预算约束，形成取舍）
- 特殊顾客：老人、手机没电的人、赶时间的骑手、代领者、抱孩子的家长
- 隐藏解法：把盖章台搬到核验台旁，合并成一窗通办

【创新点（写报名时挑 3-4 条用）】
1. 把「规定」本身变成可操作、可计量、可删除的对象，而不是嘲讽它的文案。
2. 「退还时间」作为核心计价单位：每一次改动都报出退还了多少秒。
3. 「员工疲劳」指标：机制上阻止效率优化变成负担转嫁，这是设计上的自我约束。
4. 三件工具对应身体/意识/时间三种被夺回的权力，且逐个解锁、顺序不可换。
5. 游戏最后把修改权交还给玩家本人（输入框生成卡片），作品从游戏变成工具。
6. 内置联网 Agent：玩家写下自己的困扰，AI 针对性生成剥离单（断网自动回退本地规则库）。

【技术实现】
- 单个 HTML 文件，双击即玩，断网可跑（three.js 内联，零外部依赖）
- Three.js r149 UMD 版，积木风低模，不加载外部模型文件
- 广播语音：Web Speech API + 支持导入本人录音（离线内嵌）
- 剥离单：DeepSeek API（带每日限额与断网兜底）
- 无构建、无 npm、无服务器需求

【目标用户】
被流程折磨过的每一个人：办证、报销、离职手续、排队取件。
核心人群 25–40 岁上班族，以及系统解谜类游戏玩家。

【社会价值】
它让玩家练习一种能力：面对一条不合理的规定，先问它为什么还在，
然后发现——自己有权删掉它。游戏结束时，这个动作被交还给玩家本人。

【可扩展性】
六步流程 + 12 位顾客 + 改造券的框架是通用的，可复制到医保报销窗口、
居住证办理、离职手续等场景，机制不变、只换题材。

【现场演示方式】
双击打开单个 HTML，点「▶ 演示」即可自动跑完全程（约 60 秒），
无需安装、无需联网、任何电脑浏览器可开。

【团队与进度】
两人团队，27 小时。目前已完成：门面、三幕、倒带演出、结算、剥离单、联网 Agent。

【写作要求】
- 中文，语气克制、具体，不要喊口号、不要用感叹号
- 不要编造我们没做的功能（不要写多结局、关卡编辑器、排行榜、多人）
- 如果表格有字数限制，优先保住「一句话介绍」和「核心理念」
- 每个填写项给我可直接粘贴的成稿，不要给我选项让我自己挑
```

## 补充：如果表格问这些栏，用这些答案

| 栏位 | 答案 |
|---|---|
| 参赛赛道 | 社会创新 / 公共服务 redesign（社区、公共空间、医疗可迁移） |
| 作品类型 | 网页游戏（单文件 HTML） |
| 是否需要安装 | 否，浏览器打开即玩 |
| 是否联网 | 否（联网仅用于最后剥离单的 AI 生成，断网自动降级） |
| 运行环境 | 任何现代浏览器；已适配 1280×720 起 |
| 开源/第三方 | three.js（MIT）；无其他依赖 |
| 演示形式 | 现场可玩 + 60 秒自动演示 + 录屏兜底 |

## 一句提醒

**不要让它吹。** 评委玩到的就是现在这一版，写一版自己没做的（多关卡、编辑器、排行榜）会在答辩时露馅。
上面「创新点」6 条里，**第 1、2、3、5 条是真的做出来了**，优先用这四条。
