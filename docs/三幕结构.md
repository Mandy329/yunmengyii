# 三幕结构：规训 → 觉醒 → 剥离

> 这不是一个"讽刺流程"的游戏。
> 这是一次**主体性的训练**：先让你被规训，再让你夺回，最后让你带着这副眼睛回到现实。

---

## 总纲

| 幕 | 名字 | 玩家状态 | 交还给他的东西 |
|---|---|---|---|
| 第一幕 | **规训** | 无力、服从、习得性无助 | — |
| 第二幕 | **觉醒** | 愤怒有了对象，第一次说出"为什么" | **时间 / 意识 / 身体** |
| 第三幕 | **剥离** | 把这个动作迁移到自己身上 | 一副能看见规训的眼睛 |

**铁律：顺序不可颠倒。**
没有第一幕的无力，第二幕的爽就是廉价的；没有第二幕的夺回，第三幕的说教就是空的。

---

# 第一幕｜规训（让玩家真的被驯服）

## 设计目标
不是让他"看到"荒谬，是让他**身体先记住**顺从。

## 必须做到的六件事

| # | 机制 | 造成的感受 |
|---|---|---|
| 1 | **不许跳过**。必须亲手走完六步，一步一步 | 身体先被训练 |
| 2 | **越努力越糟**。帮忙反而制造更多堵塞 | 努力无效 → 习得性无助 |
| 3 | **修订笔是灰的**。此时点它会提示：「你还没有资格修改规定。」 | 明确告知：你没有权力 |
| 4 | **视线被牵引**。每次该去下一站时，镜头自动转过去 | 连"看什么"都不由你 |
| 5 | **广播催促**。每隔几秒念一次号码，语速不变 | 时间被别人切走 |
| 6 | **移速被压制**，走不快，会被队伍挤住 | 身体不由自己 |

## 第一幕必须出现的话

> **「请先证明你排过队。」**

> 广播：「A037 号，请先出示纸质凭证副本。」
> 广播：「A037 号，您的章不符合规定。」
> 广播：「请重新排队。」

## 第一幕的结束标志
玩家第一次说出："这也太荒谬了。"
**只有这时，才允许进入第二幕。**（设计上：必须集齐三个章后才解锁）

---

# 第二幕｜觉醒（夺回三种权力）

## 核心设计：**三件工具 = 三种被夺回的权力**

这是整个作品最关键的设计决定：

| 工具 | 夺回的是 | 对应玩家说的 |
|---|---|---|
| **修订笔**（改规定） | **对规则的权力 → 意识** | 夺回意识的掌控权 |
| **搬运**（动空间） | **对空间的权力 → 身体** | 夺回身体的掌控权 |
| **退还计时器**（累计数字） | **对时间的权力 → 时间** | 夺回时间的掌控权 |

**时间 / 意识 / 身体 —— 三件工具，正好对应你说的三样东西。**
这不是巧合，这是可以直接讲给评委听的设计。

## 觉醒的触发演出

1. 玩家第三次被盖章台退回的那一刻，**镜头第一次可以由自己转动**
   ——"看什么"的权力回到手上
2. 墙上那张 1998 年的旧通知变成可点击
3. 点下去：全场变灰，只剩一步亮红灯
   > **「有 128 人，正在为这张纸打工。」**
4. **音乐第一次出现**（前 30 秒只有广播和环境噪声）
5. 修订笔从灰色变成亮色。
   > 提示语从「你还没有资格修改规定」
   > 变成 **「你有权修改它。」**

## 第二幕的标志动作
把垫花盆的那台扫描仪拖出来，**花盆摔碎**。
——这是一个祭坛上的动作：把被废置的能力重新启用。

## 夺回的瞬间（全作品最重要的一秒）
> **「你为每位市民退还了 4 分 30 秒。」**

---

# 第三幕｜剥离（把这个方法带回家）

## 设计目标
让玩家在游戏结束后，**对自己的生活做一次同样的动作**。
这是整部作品从"作品"变成"产品"的那一跳。

## 机制（成本低，价值最高）

**结算页不是终点。结算页的最后一屏是一个输入框：**

```
┌──────────────────────────────┐
│  你在这座城市删掉了一条。     │
│                              │
│  「请写出一条你身边·         │
│    一直都这样的规定。」       │
│                              │
│  [ ______________________ ]  │
│                              │
│        [ 剥离它 ]            │
└──────────────────────────────┘
```

玩家输入后，系统生成一张卡片：
- 这条规定每天消耗他多少时间
- 它的"起因猜想"（当年为什么要设这条）
- 一句重做建议
- **可保存、可分享**

## 第三幕必须出现的话

> **你已经在这座城市删掉了一条。**
> **现在，轮到你自己的那座。**

> 明天早上，找出第一条你想删的规定。

## 最后一屏

曾经摆满复印机的地方，现在放着一张长椅。
有人坐在那里喝水。

> **世界不会自己变好，
> 是有人把多余的那一层撕掉了。**

---

# 三幕对应的评分维度

| 幕 | 打哪个分 |
|---|---|
| 第一幕 规训 | 主题完成度（评委亲身体验到"被规训"） |
| 第二幕 觉醒 | 创新性（三件工具 = 三种权力的设计） |
| 第三幕 剥离 | **市场需求与商业价值**（它成了工具，有了输入与输出） |

---

# 一句话概括整个三幕

> **我们先还原你是怎么被驯服的，
> 再让你亲手撕掉一条，
> 最后把这个动作交还给你自己。**

---

# 附录 A｜3D 里怎么实现：控制权的移动曲线

**原则：限制即叙事。** 自由度本身就是剧本。

| 幕 | 控制权 | 相机 | 工具 | 玩家能做的最多的事 |
|---|---|---|---|---|
| 一 规训 | **脚本全控** | 自动转向下一站 | 全灰 | 顺从 |
| 二 觉醒 | **逐步交还** | 第一次可自己转动 | 逐个解锁 | 挪 → 改 → 记 |
| 三 剥离 | **完全交还** | 拉远到整座城市 | 收起 | 写出自己的那条 |

**工具不是一次给三个，是逐个夺回**（顺序不可换）：
1. **搬运**（身体）→ 最容易，先给你
2. **修订笔**（意识）→ 最难，最后给你
3. **退还计时器**（时间）→ 不是工具，是账本，你改完它才开始跳

# 附录 B｜三件工具的来历（继承物）

你继承的维修公司里有一个铁盒，是上一任善后员留下的。
里面三样东西和一本账本。

| 遗物 | 铭文 | 来历 |
|---|---|---|
| **搬运手套** | 「从来没有摆错的东西，只有懒得搬的人。」 | 师父为了给坐轮椅的人腾一条路，把整个窗口往左挪了三十厘米。没申请，直接搬。第二天挨骂，第三天路留在那儿了 |
| **流程连接器** | 「路是被走出来的，也是被接出来的。」 | 大厅里那条没人走过的捷径，是他一截一截接出来的 |
| **修订笔** | 「规定是人写的。」 | 师父一辈子只用过三次。**第三次之后，他被调走了。** 这就是为什么它一开始是灰的 |
| **账本** | 封面：「归还记录（待填）」第一页写着 0 小时 | 它不是工具，是你的眼睛。改完之后它才开始跳 |

# 附录 C｜剥离时刻：倒带（核心演出）

## 触发点
玩家点开墙上那张 1998 年的旧通知。

## 分镜（全程约 12 秒）

| 秒 | 画面 | 声音 |
|---|---|---|
| 0–1 | 全场变灰，只剩"复印"这一步亮红灯。「有 128 人，正在为这张纸打工。」 | 环境音消失，只剩心跳 |
| 1–5 | **倒带**：地上的纸飞回复印机、顾客倒着走回门口、印章从纸上抬起。色温由灰黄变暖 | 倒放音效 + 磁带咔哒声 |
| 5–6 | 停在 **1998 年的那一天**——打印机刚坏掉的那天。画面安静 | 静音 |
| 6–9 | 弹出当年的两个选项：<br>A. 修好它（要打报告，很贵）<br>B. 让顾客自带复印件（今天就能解决）<br>「他选了 B。**这在当时，是合理的。**」 | 音乐第一次出现 |
| 9–12 | 快进：规定长出第二个章、第三个窗口、第二台复印机。回到现在这个堵死的大厅 | 噪声层层叠加，越来越吵 |
| 12 | 定帧。字幕：<br>**「当时那个选择是合理的。<br>但现在，你可以替他重做一次。」**<br>→ 修订笔亮起 | — |

## 为什么这段是全片最重要的 12 秒
它不是在骂人。它让玩家第一次看见：**任何一条规定，都有一个可以被重写的时刻。**
这就是"原来我还有机会、还有选择"的物理形态。

## 实现建议（给技术）
**不要做真正的物理倒放。** 记录一遍正常流程里关键物体的位置序列，反向插值播放即可（预置关键帧）。成本比实时倒放低得多，且完全可控。

# 附录 D｜第三幕：剥离单卡片模板

输入框：「请写出一条你身边·一直都这样的规定。」

生成的卡片：

```
┌────────────────────────────┐
│  一直都这样 · 剥离单        │
│                            │
│  规定：每天都要写日报        │
│                            │
│  每年消耗：约 60 小时        │
│  （≈ 7.5 个工作日）         │
│                            │
│  当年为什么设它：            │
│  管理者看不见进度，          │
│  所以用文字代替观察。        │
│                            │
│  现在为什么不必了：          │
│  协作工具让进度本身可见，    │
│  它退化成了"证明我在工作"。  │
│                            │
│  重做建议：                 │
│  改为每周一次，且只写        │
│  「卡住的事」。              │
│                            │
│  —— 你有权修改它。          │
│  [ 保存图片 ]  [ 分享 ]     │
└────────────────────────────┘
```

卡片五段结构（固定）：
**规定 → 每年消耗 → 当年为什么设它 → 现在为什么不必了 → 重做建议**

收尾签名句永远不变：**「你有权修改它。」**

# 附录 E｜Redesign 到底体现在哪里（三层）

**第一层：重做的对象换掉了。**
别人重做的是物件——红绿灯、电梯按钮、登记表。
我们重做的是**一个从来不被当作"设计物"的东西：规定，以及它征收的等待。**
第一次把一个被认为天然的体验，变成可操作、可计量、可删除的对象。

**第二层：重做的方法换掉了。**
通常的重做是"加"——更好的界面、更多功能。
我们的主张是**减法作为设计方法**，并且用机制证明它真的更好：
"员工疲劳"指标存在的唯一目的，是阻止你把一个地方 burdens 转移到另一个地方。
**可以检验的减法，才是 Redesign。**

**第三层（最锋利）：重做的能力被交出去了。**
别人的 Redesign 是"我们替你重做了一个东西"。
我们的是：**从此你自己能发现它、剥离它。**
3D 那一局只是训练场，输入框才是本体。

> **一句话：我们的 Redesign，重新发明的不是某个物件，
> 而是"一个人面对规则时的位置"——
> 从服从者，变成有权修改者。**
