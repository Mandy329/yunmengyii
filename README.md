## 它 redesign 了什么

不是某个物件，是**一个人面对规则时的位置**——从服从者，变成有权修改者。

历史遗留规定从不失效：二十年前打印机坏了，于是要求顾客自带纸质复印件；设备修好后，规定留下了。问题不是没人发现，而是**发现的人没有改动权**。这个作品把改动权交给玩家。

## 三幕

| 幕 | 体验 |
|---|---|
| **一 · 认命** | 十二个人把大厅塞满，广播每 5 秒催一次，移速被压到 60%。点「修改规定」只会得到：*你还没有资格修改规定。* |
| **二 · 觉醒** | 发现 1998 年的旧通知，倒带回那天——当年打印机坏了，负责人选了「让顾客自带复印件」。**这在当时，是合理的。** 此后规定长出第二个章、第三个窗口、第二台复印机。 |
| **三 · 剥离** | 删掉那一步，复印机塌成长椅，员工坐下喝水。结算出现四个数字，以及「你为每位市民退还了 X 秒」。最后一屏是输入框：请玩家写下自己身边那条「一直都这样」的规定，生成可保存、可分享的「剥离单」。 |

## 核心机制

- **三件工具 = 三种被夺回的权力**：搬运手套（空间）、修订笔（规则）、退还计时器（时间），逐个解锁、顺序不可换
- **「退还时间」是计价单位**：每一次改动都报出退还了多少秒
- **「员工疲劳」指标**：机制上阻止效率优化变成负担转嫁——负担不能转移，只能消失
- **三条可改的规定 + 六张改造券**：预算约束形成取舍
- **隐藏解法**：把盖章台搬到核验台旁，合并成一窗通办

## 设计上的自我约束

1. 等待不是天经地义的，**等待是被设计出来的**——所以它可以被重新设计。
2. **可以检验的减法，才是 Redesign。**
3. 退还时间的终点不是效率，是一个人本来该有的一天。
